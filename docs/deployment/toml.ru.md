# Конфигурация с использованием TOML-файла

Все поддерживаемые опции приведены в файле docs/deployment/example.toml.

Значения **по умолчанию** взяты из src/common/toml-config.c; они же проставлены в [примере](./example.toml).

## Отдельные таблицы

### `[[secret]]` - секреты для подключения клиентов

| Переменная | По умолчанию | Тип данных | Обязательный | Описание | Ограничение |
|------------|--------------|------------|--------------|----------|-------------|
| `key` | `""` | Строка | Обязательный | Секрет в шестнадцатеричной системе | 32 символа |
| `label` | `""` | Строка | Не обязательный | Метки идентифицируют, какой секрет использует подключение | 32 символа, буквы/цифры, `-` и `_` |
| `limit` | `0` | Число | Не обязательный | // TODO: Количество клиентов, одновременно использующих один секрет? | // TODO: |
| `quota` | `0` (безлимит) | Число или строка | Не обязательный | Ограничение суммарного объёма переданных данных (принятых + отправленных) по секрету; при исчерпании активные подключения закрываются, новые отклоняются. Настраивается в байтах или в читаемом формате (`"10K"`, `"10M"`, `"10G"`, `"10T"`) | Нет |
| `rate_limit` | `0` (безлимит) | Число или строка | Не обязательный | Ограничение скорости передачи данных на один IP. Настраивается в байтах или в читаемом формате (`"10K"`, `"10M"`, `"10G"`, `"10T"`) | Нет |
| `max_ips` | `0` (безлимит) | Число | Не обязательный | Ограничение числа уникальных клиентских IP, одновременно использующих секрет. Дополнительные подключения с уже подключённого IP всегда разрешены. | Нет |
| `expires` | `0` (никогда) | Число | Не обязательный | Срок действия секрета - автоматическое отключение секрета после метки времени (`expires = 2025-12-31T23:59:59Z`). Существующие подключения продолжают работать; отклоняются только новые. | Нет |
